# Documentation governance report

- Mode: audit (default, zero writes) | explicitly requested fix
- Scope and factual sources read:
- Findings: path/anchor, evidence, impact, proposed correction, uncertainty
- Edits: none in audit; exact authorized paths/corrections in fix
- Deferred structural work: exact proposal and confirmation needed
- Verification:
  - passed: command/result/date and verified scope
  - failed: command/exit or error/date
  - not-run: check/reason
- Limits: unverified remote links, model behavior, packaging/profile gates, translation uncertainty as applicable

Report in the response during audit. This template is not permission to create a report file.
